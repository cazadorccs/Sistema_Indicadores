# Directorio de Usuarios y Credenciales de Prueba (Ambiente Local)
## Sistema de Gestión y Despliegue Operativo (SGDO - VSCC / MPPCI)

> [!NOTE]
> En este entorno de desarrollo local, el sistema de autenticación admite cualquier contraseña para ingresar (ej: `123456`, `admin123` o `mppci2026`). Como identificador de acceso se puede utilizar la **Cédula de Identidad**, el **Correo Electrónico**, el **ID de Usuario** o las **Siglas del Ente**.
> Además, desde la cuenta de Administrador se puede utilizar el botón **"👁️ Simular Vista"** dentro del módulo de *Gestión de Usuarios* para cambiar de perfil instantáneamente sin necesidad de cerrar sesión.
