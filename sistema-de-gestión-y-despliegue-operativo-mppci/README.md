# Sistema de Gestión y Despliegue Operativo (SGDO) — VSCC MIPPCI

Plataforma unificada para la rectoría, seguimiento de indicadores, telemetría de radiodifusión/TDA, monitoreo ciberdefensivo y despliegue operativo comunicacional de los 20 entes adscritos a la Vicepresidencia Sectorial de Comunicación y Cultura (VSCC / MIPPCI).

---

## 🚀 Puesta en Marcha Local

**Requisitos:** Node.js v18+

1. **Instalar dependencias:**
   ```bash
   npm install
   ```
2. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```
   El sistema quedará disponible en `http://localhost:3000`.
